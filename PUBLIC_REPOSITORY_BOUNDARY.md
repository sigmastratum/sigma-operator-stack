# SOS Public Repository Boundary

Status: public Community Alpha source and distribution boundary

This repository is the public source home for the Sigma Operator Stack
Community core. Public visibility and an installable alpha do not permit
private material, broaden platform support, or authorize promotion claims.

## Allowed

- product source under `src/sos`;
- public schemas, reason codes, templates and compatibility contracts;
- synthetic repository fixtures and hermetic tests;
- public-safe architecture, threat model, CLI and user documentation;
- package metadata, dependency locks, SBOM, provenance and release workflows;
- standard open-source project files and content-safe public evidence.

## Forbidden

- credentials, secrets, environment values or authenticated URLs;
- user/customer/session/production content or identifiers;
- raw prompts, messages, responses, transcripts or attachments;
- private paths, hosts, infrastructure or deployment details;
- private roadmaps, commercial planning, owner approvals or internal receipts;
- internal operator configuration, personas or write-capable authority;
- private/internal/Runtime Git history or bulk-copied source;
- unlicensed third-party material;
- hidden telemetry, hosted-account requirements or remote control.

## Reuse Rule

Private or internal code is not imported. A generic algorithm may be
reimplemented only against a public contract after ownership/license review,
content-safety scans, synthetic qualification and independent review of the
exact public diff.

## Public Core Boundary

The public core is local-first and offline-capable. It must remain
useful without a hosted account and must retain local record access, export,
uninstall, stale detection, security fixes and public schemas. Future paid
team or hosted services are separate products and must consume versioned public
contracts without weakening this boundary.

No commit, push, package publication, promotion or visibility change is
authorized merely by this document.
