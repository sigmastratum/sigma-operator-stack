# Private-alpha tester note

This document is retained only to identify historical invited-test evidence.
It is **not** public installation authority and intentionally contains no
download or command sequence.

The only public route is
[`install-with-codex.md`](install-with-codex.md). Before a qualified public
release publishes `release/current.json`, that route stops without selecting
an artifact.

Invited testers must use the exact content-safe packet supplied for their
bounded test. Packet-specific instructions do not establish a release, public
platform support or an alternative quickstart.

Never send project source, raw `.sigma` records, prompts, credentials or
absolute paths in feedback. Use [`alpha-feedback.md`](alpha-feedback.md).
