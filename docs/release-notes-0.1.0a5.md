## What changed

- Resumed installation confirmation is bound to the exact previewed plan.
- Seed, digest, repository-state or launcher drift fails before mutation.
- Project trust and sandbox restrictions remain explicit interactive handoffs.
- Same-version maintenance rediscoveries verify a fresh canonical archive.

## Trust boundary

- The human approves the exact project mutation preview.
- SOS does not change PATH, shell profiles, system Python or package managers.
- SOS is local and telemetry-free after verified acquisition.
- Qualification remains separate and may honestly be `not_configured` or
  `not_verified` after installation.
- Removal deletes only SOS-managed integration and the SOS-owned runtime;
  `.sigma` and unrelated user files remain.
- The macOS archive is unsigned and not notarized. It may require an explicit
  **Open Anyway** decision and is not a notarization-complete promotion claim.
