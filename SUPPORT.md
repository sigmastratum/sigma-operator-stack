# Support

- Questions, usage help and reproducible product bugs: the matching typed
  GitHub Issue. Discussions and blank issues are disabled during the alpha.
- Vulnerabilities: GitHub private vulnerability reporting, as described in
  [SECURITY.md](SECURITY.md).

The community alpha is provided without an uptime, response-time or
compatibility SLA. Include `sos --version`, the documented support-boundary
facts and a synthetic reproducer. Do not post secrets, private repository
content, host identifiers, prompts or responses.

Maintainers target initial classification within five working days when the
report contains the required synthetic reproducer. This is best effort, not an
SLA or a promise of a fix.
